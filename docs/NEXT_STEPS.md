# Next steps

*Plain-language note: what version 0.2 and later could add, so v0.1 is understood as a first step.*

- More labels: add Ni-Cu-PGE occurrences from the Michigan and Wisconsin geological surveys and published literature (for example, intrusions near Eagle) as weak labels; test positive-unlabeled learning when there are at least 10.
- Depth: add depth-to-basement or depth-to-source estimates (Euler deconvolution) so covered targets can be ranked by reachability.
- Gravity: add USGS or state gravity data; Ni-Cu intrusions are dense.
- Chemistry: MCR-GeoChem v1.1 sampling gap near Eagle and the Baraga basin; re-test chemistry once coverage exists.
- Extend to Minnesota once Earth MRI airborne data cover the Duluth Complex, making a true multi-deposit test possible.
